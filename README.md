# 링크 | 매장 주문·결제 웹 MVP

Android 앱 MVP의 화면, 디자인 토큰, Noto Sans KR, Figma 에셋, 카탈로그와 주문 상태 전이를 재사용한 웹 버전입니다. 기준은 앱의 `8be79a1` 커밋이며, 이 폴더에서 독립적으로 실행됩니다.

## 실행

Node.js 22.12 이상이 필요합니다. `MVP_Web`에서 실행하세요.

```powershell
npm ci
npm run dev
```

브라우저에서 [로컬 개발 주소](http://127.0.0.1:5173/)를 엽니다. 같은 네트워크의 휴대폰에서 화면을 확인하려면 `npm run dev -- --host 0.0.0.0`으로 실행하고 PC의 LAN 주소와 포트 `5173`에 접속합니다.

## 데모 주문

1. 첫 사용법 4단계를 진행하거나 건너뜁니다.
2. 매장 탐색 화면에서 **데모로 체험하기**를 선택합니다.
3. 매장을 확인하고 메뉴·옵션·수량을 고릅니다. 메뉴에 담은 뒤 하단의 고정 장바구니 버튼을 누릅니다.
4. 테스트 결제를 완료하고 주문 상태를 확인합니다. 약 25초 후 준비 완료로 바뀝니다.
5. 픽업을 완료한 뒤 같은 매장을 선택하면 재주문 경로가 표시됩니다.

취소·실패·시간 초과도 테스트 결제 화면에서 재현할 수 있습니다. 장바구니, 주문 이력, 진행 중인 결제, 접근성 설정은 브라우저의 로컬 저장소에 남습니다. 데모는 서버 없이 실행됩니다.

## 브라우저별 동작

- **매장 탐색**은 지원 브라우저의 보안 컨텍스트에서 사용자가 **블루투스로 매장 찾기**를 누르면 브라우저의 기기 선택 창을 엽니다. 카탈로그에 등록된 비콘 이름을 사용합니다. 매장 이름 검색과 데모는 브라우저의 Bluetooth 지원과 관계없이 이용할 수 있습니다.
- **다시 듣기와 음성 검색**은 브라우저 음성 API를 사용합니다. 음성 검색을 지원하지 않거나 마이크 권한이 없을 때도 직접 입력으로 검색할 수 있습니다. 음향과 진동은 브라우저 및 기기 설정에 따릅니다.
- **외부 주문 서버**는 설정의 **개발·테스트 연결**에서 지정합니다. 별도 출처라면 서버가 웹 출처와 인증 요청을 허용하도록 CORS와 쿠키를 설정해야 합니다. 외부 결제 창은 새 탭으로 열리며 결제 결과는 서버에서 조회합니다.
