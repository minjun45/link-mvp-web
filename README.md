# 링크 | 매장 주문·결제 웹 MVP

Android 앱 MVP의 화면, 디자인 토큰, Noto Sans KR, Figma 에셋, 카탈로그와 주문 상태 전이를 재사용한 웹 버전입니다. 기준은 앱의 `8be79a1` 커밋이며, 이 폴더에서 독립적으로 실행됩니다.

## 실행

Node.js 22.12 이상이 필요합니다. `MVP_Web`에서 실행하세요.

```powershell
npm ci
npm run dev
```

브라우저에서 [로컬 개발 주소](http://127.0.0.1:5173/)를 엽니다. 같은 네트워크의 휴대폰에서 화면을 확인하려면 `npm run dev -- --host 0.0.0.0`으로 실행하고 PC의 LAN 주소와 포트 `5173`에 접속합니다.

## 데모 주문

1. 첫 화면에서 **데모 매장으로 진행하기**를 선택합니다.
2. **주변 매장을 찾고 있어요** 화면에서 약 2초 후 후보 매장 목록으로 이동합니다. 데모에서는 Bluetooth를 사용하지 않으며, 로컬 테스트 모드로 진행합니다.
3. 매장을 확인하고 메뉴·옵션·수량을 고릅니다. 메뉴에 담은 뒤 하단의 고정 장바구니 버튼을 누릅니다.
4. 테스트 결제를 완료하고 주문 상태를 확인합니다. 약 25초 후 준비 완료로 바뀝니다.
5. 픽업을 완료한 뒤 같은 매장을 선택하면 재주문 경로가 표시됩니다.

취소·실패·시간 초과도 테스트 결제 화면에서 재현할 수 있습니다. 장바구니, 주문 이력, 진행 중인 결제, 접근성 설정은 브라우저의 로컬 저장소에 남습니다. 데모는 서버 없이 실행됩니다.

실제 탐색은 첫 화면의 **실제 매장 찾기**를 누르면 시작합니다. 사용법 4단계는 **설정 → 사용법 다시 듣기**에서 확인할 수 있습니다. 주문을 마치거나 탐색에서 뒤로 가면 첫 선택 화면으로 돌아갑니다. 진행 중인 결제가 있는 상태로 새로고침하면 먼저 기존 결제 결과를 확인합니다.

## 브라우저별 동작

- **매장 탐색**은 첫 화면의 **실제 매장 찾기** 클릭 안에서 즉시 Bluetooth 기기 선택 창을 열고 `V5-01`에서 최대 15초 동안 결과를 기다립니다. 탐색 화면에는 추가 Bluetooth 버튼이 없습니다. 브라우저의 사용자 입력 조건을 지키기 위해 요청을 화면 전환 후의 effect나 비동기 데이터 로딩 뒤로 미루지 않습니다. 지원하지 않는 브라우저·권한 거부·미탐색은 `V5-01e`에서 다시 찾기와 이름 검색을 안내합니다. [Web Bluetooth 동작 설명](https://developer.chrome.com/docs/capabilities/bluetooth).
- **매장 이름 검색**은 목록의 **찾는 매장이 없어요** → 해결 방법 안내(`V5-02e`) → **매장 이름으로 찾기**(`V5-02s`) 순서로 이용합니다. 탐색을 멈추거나 미탐색 화면에서도 진입할 수 있습니다. 거리·위치를 측정하지 않으므로 카탈로그의 참여 매장을 검색하며, 대기 정보가 없으면 매장에서 확인하도록 안내합니다.
- **BLE 기기 진단**은 설정의 **이름 필터 없이 BLE 기기 찾기**에서 실행합니다. 브라우저가 선택할 수 있는 BLE 기기를 매장 이름 제한 없이 표시하고, 선택한 기기의 이름과 등록된 비콘 이름을 비교합니다. 진단은 기기의 GATT 서버에 연결하거나 주문 매장으로 등록하지 않습니다. 진단에서는 휴대폰이 보이는데 일반 매장 찾기에서는 보이지 않으면 실제 광고 이름과 `catalog.json`의 `beaconName`을 먼저 비교하세요. 진단에서도 보이지 않으면 광고 실행·Connectable·기기/드라이버 지원을 확인해야 합니다.
- **주문 상태·주문번호 다시 듣기, 도움 카드의 안내 듣기와 음성 검색**은 브라우저 음성 API를 사용합니다. 음성 검색을 지원하지 않거나 마이크 권한이 없을 때도 직접 입력으로 검색할 수 있습니다. 음향과 진동은 브라우저 및 기기 설정에 따릅니다.
- **외부 주문 서버**는 설정의 **개발·테스트 연결**에서 지정합니다. 별도 출처라면 서버가 웹 출처와 인증 요청을 허용하도록 CORS와 쿠키를 설정해야 합니다. 외부 결제 창은 새 탭으로 열리며 결제 결과는 서버에서 조회합니다.
